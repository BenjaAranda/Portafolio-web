# Seguridad

Si encuentras una vulnerabilidad en este portafolio, usa la opción **Report a vulnerability** de la pestaña Security del repositorio para comunicarla de forma privada. No publiques credenciales, datos personales ni detalles explotables en un issue.

El sitio de ejemplo no requiere claves para ejecutarse con los datos iniciales. La configuración de Sanity y Vercel debe suministrarse mediante variables de entorno; nunca debe subirse un archivo `.env` ni un token al repositorio.
